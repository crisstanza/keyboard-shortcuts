# Keyboard Shortcuts

<br>

## VSCode:

### Windows:

- `Alt+D`: duplicate line or selection
- `Alt+Z`: word wrap
- `Ctrl+K, Ctrl+0`: collapse all
- `Ctrl+Shift+]`: navigate from/to the beginning/end of a code block
- `Ctrl+Shift+S`: save as

<br>

## Visual Studio:

### Windows:

- `Ctrl+D`: duplicate line or selection
- `Ctrl+Shift+P`: code search/feature search
- `Ctrl+Ç`: search solution explorer
- `Ctrl+K, Ctrl+D`: format document
- `Ctrl+R, Ctrl+G`: remove and sort usings
- `Ctrl+R, Ctrl+T`: debug tests
- `Ctrl+R, T`: run tests
- `Ctrl+Alt+PageUp`: navigate to the file to the left
- `Ctrl+Alt+PageDown`: navigate to the file to the right
- `Ctrl+Shift+S`: save all
- `Ctrl+M, Ctrl+L`: expand all
- `Ctrl+M, Ctrl+M`: expand or collapse depending on the cursor position
- `Ctrl+M, Ctrl+O`: collapse to definitions

<br>

## Windows:

- `Win+Shift+S`: copy image from screen
- `Win+Shift+T`: copy text from screen
- `Win+.`: insert emoji
